# 1.3.1 验证记录

日期：2026-09-15。

## 本次直接复现的原因

原核心清单使用 `av>=16.0.0`，0.35.0 使用 `av>=17.0.0`，而整合包已安装 av 17.1.0。旧更新器在解析依赖前要求变更前后必须是 `==` 精确版本，并且禁止 av 变更，导致可满足的更新被拒绝。
