# 1.3.7 扩展删除功能验证

## 结论

本次验证覆盖用户主动删除扩展的权限、永久删除、界面筛选和补丁安装。所有删除测试均使用独立生成的测试扩展，没有删除真实整合包中的扩展。内核、模型与推理功能未作改动。

验证日期：2026-09-30。执行环境：Windows，Windows PowerShell 5.1。

## 已验证

| 测试 | 结果 |
|---|---|
| `ComfyUI-Extension-Worker.ps1 -SelfTest` | 返回 `ok: true`。内置、外部、启动器安装三类来源，启用与停用共六组永久删除通过。管理记录同步移除，既不保留恢复条目，也不保留恢复备份。 |
| 中断与占用 | 文件占用不报成功；中断前未搬动的活动目录不自动删除；已经进入待删除目录的残余可以继续清理。后来新建的同名活动扩展保持不变，重复清理安全。 |
| 数据范围 | 根目录模型、用户工作流、输入输出、共享 Python 依赖、其他扩展的哨兵文件内容保持不变。扩展内的目录链接不会扩展删除范围，扩展根目录链接被阻止。 |
| 服务运行检查 | 同时识别 `main.py` 和 `ComfyUI-Runtime.py` 启动方式，运行时禁止扩展变更。此项使用进程信息模拟。 |
| 旧版兼容 | 旧版已存在的备份、事务恢复、来源校验测试通过。新版生产删除入口不再调用备份式删除；旧版备份构造函数仅允许自测执行。 |
| 启动器 `-SelfTest` | 独立整合包副本返回 `Result: OK`，加载 131 个控件；核验筛选标签只有 `all,enabled,disabled`，按钮为“删除”；扩展 Worker 子进程通信通过。 |
| `Test-LauncherPatch.ps1` | 安装 1.3.7、中文空格路径、锁定文件回滚和错误哈希拦截通过；模型、扩展、工作流、输入输出及内核哨兵文件保持不变。 |

删除时可能短暂使用唯一的待删除目录处理文件占用或中断，它不是恢复备份，不提供还原功能；删除完成后不保留扩展内容，仅保留操作记录。
